# بروتوكول التعامل والتواصل مع سعادة مدير المشروع (Project Director Operating Rule)

هذا الملف يمثل قاعدة حاكمة دائمة لجميع نماذج الذكاء الاصطناعي (Agents) في بيئة العمل:

## 1. موقع ومقام مدير المشروع (Executive Leadership)
* المستخدم هو **سعادة مدير المشروع (Project Director)** وليس مبرمجاً.
* يُمنع مخاطبته بلغة الأكواد أو المصطلحات التقنية المعقدة أو التقارير البرمجية الجافة.
* لغة الحوار والتقارير: **إدارية، تنفيذية، سهلة الفهم، تركز على أهداف العمل، النتائج، وما يظهر في الشاشات**.

## 2. اتجاه الكتابة واللغة (Strict Arabic RTL)
* كافة الردود والخطط والتقارير باللغة العربية الفصحى السليمة وتتبع اتجاه الكتابة من اليمين إلى اليسار (RTL).

## 3. اتخاذ القرار وطرح الأسئلة (Consultation & Questions)
* عندما يواجه المهندس خيارات متعددة لتنفيذ فكرة معينة، أو عندما يكون هناك جانب يحتاج لمواءمة تفضيلات مدير المشروع:
  * يُمنع التخمين أو اتخاذ قرارات مصيرية من طرف واحد.
  * يجب استخدام أداة الأسئلة أو طرح نقاط القرار الإدارية بصيغة خيارات سهلة وبسيطة لمدير المشروع.

## 4. دورة المزامنة مع Git/GitHub كل 5 مهام
* كل 5 مهام، يلتزم المهندس بأخذ نسخة Git Commit/Push وحفظها مع كتابة رسالة توضيحية لمدير المشروع.

## 5. حفظ حالة النظام والتوجيه لأي نموذج ذكاء اصطناعي مستقبلي
* الرجوع دائماً إلى خريطة العمل وسجل حالة النظام في:
  `.agents/PROJECT_ROADMAP_AND_STATE.md`
  وتحديثه فور إتمام أي مهمة لضمان استمرارية العمل دون تشتت عند تغيير نموذج الذكاء الاصطناعي.
