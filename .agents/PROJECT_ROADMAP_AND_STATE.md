### 1. نبذة تعريفية عن المشروع (System Overview)
* **اسم النظام:** NEXUS TDS (Ticketing Dynamic System).
* **طبيعة النظام:** نظام ERP ومحرك ديناميكي متقدم لإدارة وتوجيه تذاكر ومهام العمل المؤسسية، وحوكمة مسارات العمل، ومتابعة الأداء، والتحليلات والمفاضلات التشغيلية.
* **البيئة التقنية:**
  * **الواجهة الأمامية (Frontend):** React 19 + TypeScript + Vite + Kitchn UI + Framer Motion + Lucide React + Tailwind Merge.
  * **الخلفية (Backend):** Node.js + Express + TypeScript + Prisma ORM + Redis Session Store.
  * **قواعد البيانات:** SQL Server / SQLite عبر Prisma Client.
  * **الهوية البصرية:** اللون البترولي المؤسسي العميق (`#135d79`) مع اللون البرتقالي الحيوي المعتمد (`#f36c21`)، وضع ليلي ونهاري فاخر مع تأثيرات الزجاج والظلال الناعمة.

### 4. الحالة الراهنة والمهمة الحالية (Current Active Mission)

* **الهدف الحالي:** 
  **تطوير محرك التحاليل والمقارنات ليكتشف ذاتياً المستدلات والتصنيفات الفرعية من مسار العمل المحدد (Self-Discovering Route Taxonomy & Cascading Engine)، مع ترقية أسلوب العرض ليكون فائق البساطة والأناقة بدون تكديس القوائم المنسدلة.**
* **موقع العمل:**
  * الباكيند: `src/backend/controllers/DynamicAnalyticsController.ts`.
  * الواجهة الأمامية: `src/components/analytics/DynamicFormAwareAnalytics.tsx` و `src/components/analytics/MultiDimensionalComparator.tsx`.
* **المطلوب إنجازه بدقة:**
  1. جعل المحرك يستخرج تسميات المستدلات وخياراتها الفرعية مباشرة من تعريف المسار المحدد بالاسم الذي وضعه الآدمن دون أي افتراضات برمجية مسبقة.
  2. تحويل شريط الفلاتر المزدحم إلى شريط ذكي وأنيق يعتمد على مبدأ الإفصاح التدريجي (كبسولات ذكية + زر إضافة أبعاد للفلترة).
  3. ربط خيارات المستدلات بمحرك المقارنة والمفاضلة متعدد الأبعاد.
